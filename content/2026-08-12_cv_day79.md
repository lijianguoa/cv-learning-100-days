## 三、历史背景

### 3.1 遥感的诞生
遥感（Remote Sensing）的概念最早可追溯至19世纪。1858年，法国摄影师**纳达尔（Gaspard-Félix Tournachon）**乘坐热气球拍摄了世界上第一张航空照片，开启了从空中观测地球的先河。[1858年，人类首张航拍照片诞生](http://enc.newdu.com/67329.html)

### 3.2 卫星时代
- **1957年**：苏联发射**斯普特尼克1号（Sputnik 1）**，标志着太空时代的开始
- **1960年**：美国发射**TIROS-1**，第一颗气象卫星，首次从太空获取地球云图
- **1972年**：**Landsat-1**发射，开启地球资源卫星观测的新纪元，提供了多光谱扫描仪（MSS）数据
- **1999年**：**Landsat-7**携带ETM+传感器升空，全色分辨率提升至15米
- **2013年**：欧洲空间局发射**Sentinel-1A**，开启哥白尼计划，提供免费的SAR数据
- **2015年**：**Sentinel-2A**发射，提供10米分辨率的多光谱影像，成为当前最广泛使用的免费遥感数据源之一

### 3.3 数字遥感处理时代
1964年，美国喷气推进实验室（JPL）首次使用计算机处理"水手7号"发回的月球照片，校正了各种图像畸变，被认为是**数字遥感图像处理的开端**。[遥感图像处理的发展与应用](https://m.docin.com/touch_new/preview_new.do?id=1510945031)

### 3.4 深度学习革命
2012年AlexNet在ImageNet竞赛中获胜后，深度学习迅速渗透到遥感领域。2015年后，FCN、U-Net、ResNet等架构被广泛应用于遥感图像的语义分割、变化检测和目标识别任务，使遥感分析从"像素级"走向"语义级"理解。

## 四、核心概念

### 4.1 遥感图像的特点

遥感图像与普通数码照片存在本质区别：

| 特性 | 说明 | 影响 |
|------|------|------|
| **多光谱/高光谱** | 包含可见光外的波段（红外、近红外、微波等） | 可探测人眼不可见的地物信息 |
| **空间分辨率** | 像素对应的地面实际距离（如10m、30m） | 决定可识别的最小地物尺寸 |
| **时间分辨率** | 重访周期（如Sentinel-2为5天） | 影响动态监测能力 |
| **辐射分辨率** | 量化等级（如12bit vs 8bit） | 决定可区分的灰度级数 |
| **大幅宽** | 单景覆盖范围可达数百公里 | 适合大区域监测 |
| **几何畸变** | 受地球曲率、地形起伏影响 | 需要正射校正 |

### 4.2 遥感图像预处理

```python
# 使用 rasterio 读取遥感影像
import rasterio
from rasterio.plot import show

# 打开多光谱影像
with rasterio.open('sentinel2_image.tif') as src:
    # 读取红、绿、蓝、近红外波段
    red = src.read(4)      # B4 - Red
    green = src.read(3)    # B3 - Green
    blue = src.read(2)     # B2 - Blue
    nir = src.read(8)      # B8 - NIR
    
    # 计算 NDVI (归一化植被指数)
    ndvi = (nir - red) / (nir + red + 1e-8)
```

### 4.3 变化检测（Change Detection）

变化检测是通过分析同一地区不同时期的遥感图像，识别地表发生变化区域的技术。

**主要方法演进**：

| 阶段 | 时间 | 代表方法 | 特点 |
|------|------|----------|------|
| 传统方法 | 1980s-2010s | 图像差分、CVA、PCA | 基于像素统计，准确率<70% |
| 深度学习初期 | 2015-2018 | FC-EF, FC-Siam-conc | 双分支Siamese网络 |
| 时空融合时代 | 2018-至今 | STANet, BIT, ChangeFormer | 注意力+Transformer |

**经典Siamese网络结构**：
```
输入图像T1 ──┐
            ├──→ 共享编码器 ──→ 差异特征 ──→ 解码器 ──→ 变化掩膜
输入图像T2 ──┘
```

### 4.4 地物分类（Land Cover Classification）

将遥感影像中的每个像素归类到预定义的土地覆盖类别（如水体、森林、农田、建筑等）。

**常用方法**：

1. **传统机器学习**
   - 支持向量机（SVM）
   - 随机森林（Random Forest）
   - 最大似然分类

2. **深度学习方法**
   - **CNN**：用于场景级分类
   - **U-Net/U-Net++**：用于像素级语义分割
   - **DeepLab v3+**：ASPP模块捕获多尺度信息
   - **ViT/ConvNeXt**：Transformer在遥感中的应用

**常用数据集**：
- [UC Merced Land Use Dataset](http://weegee.vision.ucmerced.edu/datasets/landuse.html) - 21类，100×100像素
- [EuroSAT](https://github.com/phelber/eurosat) - 基于Sentinel-2的10类数据集
- [RESISC45](http://www.escience.cn/people/JunweiHan/NWPU-RESISC45.html) - 45类场景分类

## 五、科学家故事

### 5.1 Roger Tomlinson（1933-2014）—— "GIS之父"

1960年代，加拿大地理学家Roger Tomlinson在为加拿大土地清查项目工作时，首次提出了**地理信息系统（GIS）**的概念。他意识到传统的纸质地图无法满足大规模土地管理的需求，于是开发了世界上第一个GIS系统——**CGIS（Canada Geographic Information System）**。

Tomlinson的天才之处在于将遥感数据与计算机空间分析结合。他曾说："**地图是一种沟通工具，而GIS让这种沟通变得动态和智能。**" 今天，每一张遥感影像的分类结果、每一次变化检测的输出，都运行在GIS的框架之上。

> [Roger Tomlinson - Wikipedia](https://en.wikipedia.org/wiki/Roger_Tomlinson)

### 5.2 James Garvin 与火星遥感

NASA科学家James Garvin是火星遥感探测的关键人物之一。他主导了火星轨道器激光高度计（MOLA）项目，通过遥感技术精确绘制了火星的三维地形。他的工作证明了遥感技术不仅限于地球——**它是人类探索整个太阳系的眼睛**。

## 七、经典实验

### 实验1：基于NDVI的植被变化监测

**目标**：利用两期Sentinel-2影像，计算NDVI差值，检测植被退化区域。

**步骤**：
1. 下载2024年和2025年同一地区的Sentinel-2 Level-2A数据
2. 提取B4（红）和B8（近红外）波段
3. 分别计算两期NDVI
4. 计算NDVI差值图
5. 设定阈值（如ΔNDVI < -0.2）标识退化区域

**代码片段**：
```python
import numpy as np
import rasterio

# 读取两期影像
with rasterio.open('2024.tif') as src1, rasterio.open('2025.tif') as src2:
    red1, nir1 = src1.read(4), src1.read(8)
    red2, nir2 = src2.read(4), src2.read(8)

ndvi1 = (nir1 - red1) / (nir1 + red1 + 1e-8)
ndvi2 = (nir2 - red2) / (nir2 + red2 + 1e-8)
diff = ndvi2 - ndvi1

# 植被退化掩膜
degradation = diff < -0.2
```

> [NDVI - Wikipedia](https://en.wikipedia.org/wiki/Normalized_difference_vegetation_index)

### 实验2：使用U-Net进行建筑变化检测

**目标**：训练一个Siamese U-Net模型，检测两期高分辨率影像中的建筑变化。

**数据集**：LEVIR-CD 或 WHU-Building Change Detection Dataset

**评估指标**：
- Precision = TP / (TP + FP)
- Recall = TP / (TP + FN)
- F1-Score = 2 × Precision × Recall / (Precision + Recall)
- IoU = TP / (TP + FP + FN)

## 八、小故事

### 🛰️ "一张卫星照片拯救了一个国家"

1998年，非洲国家**博茨瓦纳**的奥卡万戈三角洲突然发生了严重的水位下降。当地牧民报告说，他们的牲畜找不到水源，整个生态系统面临崩溃。

NASA的科学家通过分析Landsat卫星的多年遥感数据，发现了一个惊人的事实：水位下降并非自然干旱所致，而是上游国家**安哥拉**的水坝建设改变了水流分配。更关键的是，遥感数据显示**三角洲的另一个区域正在形成新的湿地**——这是水流改道的结果。

基于这些卫星数据，博茨瓦纳政府重新规划了牧场和野生动物保护区的布局，将资源转移到新兴湿地区域。三年后，这个三角洲的野生动物数量不仅没有下降，反而增加了15%。

这个故事告诉我们：**遥感数据不仅是科学的眼睛，更是决策的灯塔。** 在气候变化日益严峻的今天，遥感技术正在帮助全球无数国家和地区做出更明智的环境决策。

## 十、术语表

| 术语 | 英文 | 解释 |
|------|------|------|
| 遥感 | Remote Sensing | 不直接接触目标物体，通过传感器从远处获取信息的技术 |
