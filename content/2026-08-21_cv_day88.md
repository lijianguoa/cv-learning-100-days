## 📜 一、历史背景

弱监督学习（Weakly Supervised Learning）的研究可追溯至20世纪90年代末。1997年，Thomas G. Dietterich、Richard H. Lathrop 和 Pedro Domingos 在研究药物分子活性预测时提出了**多实例学习**（Multiple Instance Learning, MIL）的框架 [Dietterich et al., 1997](https://link.springer.com/article/10.1023/A:1007331115022)。在那个问题中，每个药物分子有多种可能的低能构象（实例），但只有分子级别的标签（是否具有活性），而非每个构象的标签。这一设定催生了一个全新的学习范式——**标签在"包"（bag）级别而非实例级别**。

2000年代，多实例学习开始在生物信息学 [Ray, 2006](https://pubmed.ncbi.nlm.nih.gov/16501249/) 和图像分类 [Andrews et al., 2003](https://link.springer.com/chapter/10.1007/978-3-540-45167-9_5) 中广泛应用。2006年，Babenko 等人首次将 MIL 引入自然图像分类 [Babenko et al., CVPR 2009](https://ieeexplore.ieee.org/document/5206848)，将一张图片视为一个"包"，其中的图像块为实例。

与此同时，**标签噪声**（Label Noise）问题的研究也在深入。2013年，Natarajan 等人提出了处理类别噪声的损失修正方法 [Natarajan et al., NeurIPS 2013](https://papers.nips.cc/paper/2013/hash/0125d4094e65f49d6f84c11c1b6981ff-Abstract.html)。2018年，Northcutt 等人提出了**置信学习**（Confident Learning）框架，系统量化标签噪声 [Northcutt et al., 2021](https://arxiv.org/abs/1911.00068)，并开源了 [Cleanlab](https://github.com/cleanlab/cleanlab) 库。

在弱监督目标检测领域，2016年是关键一年。Bilen 和 Vedaldi 提出了 **WSDDN**（Weakly Supervised Deep Detection Network）[Bilen & Vedaldi, CVPR 2016](https://arxiv.org/abs/1511.02853)，首次在深度学习框架下实现仅用图像级标签训练目标检测器。同年，Zhou 等人提出了 **CAM**（Class Activation Mapping）[Zhou et al., CVPR 2016](https://arxiv.org/abs/1512.04150)，通过全局平均池化层实现了图像分类网络到目标定位的桥接。2017年，Selvaraju 等人提出 **Grad-CAM** [Selvaraju et al., ICCV 2017](https://arxiv.org/abs/1610.02391)，将 CAM 推广到任意梯度可用的网络结构，成为弱监督定位最重要的工具之一。

2018年，Ilse 等人提出了**注意力多实例学习**（Attention-based Deep MIL）[Ilse et al., ICML 2018](https://arxiv.org/abs/1802.04712)，用注意力机制替代传统的 max/mean 算子，实现了端到端可训练的 MIL 框架，为医学影像分析（尤其是病理全切片图像分析）带来了革命性突破。

了解更多关于弱监督学习的综述，可参阅周志华团队的经典综述 [Zhou, 2017](https://link.springer.com/book/10.1007/978-3-319-64430-5) 以及中文讲解视频 [B站：弱监督学习综述](https://www.bilibili.com/video/BV1xx411c7mD)。

## 🧠 二、核心概念

### 2.1 弱监督的三种类型

弱监督学习通常分为三大类，它们的共同点是：标签信息不如全监督（fully supervised）那样精确和完整。

| 类型 | 英文 | 标签特征 | 典型场景 |
|------|------|----------|----------|
| 不完全监督 | Incomplete Supervision | 仅有少量样本有标签 | 半监督学习、主动学习 |
| 不确切监督 | Inexact Supervision | 标签粒度粗于任务需求 | 图像级标签做目标检测/分割 |
| 不准确监督 | Inaccurate Supervision | 标签可能存在错误 | 标签噪声学习 |

周志华教授在其著作 [《Machine Learning》](https://link.springer.com/book/10.1007/978-3-319-64430-5) 中对此做了经典分类。三种类型可以组合出现，例如在医学影像中同时存在标注不足（不完全）和粗粒度标签（不确切）的情况。

**不确切监督**是计算机视觉中研究最多的方向。典型例子是：仅有图像级标签（"这是一张猫的照片"），却需要训练出能定位猫在图片中具体位置（边界框）的检测器。这类问题也被称为**弱监督目标检测**（Weakly Supervised Object Detection, WSOD）。

### 2.2 多实例学习（Multiple Instance Learning, MIL）

多实例学习是不确切监督的核心框架。在 MIL 中，训练数据由若干"包"（bag）组成：

- 每个包包含多个实例（instance）
- 标签仅在包级别给出（正包/负包）
- **标准MIL假设**：一个包为正，当且仅当其中至少一个实例为正

形式化定义：给定包集合 $B = \{B_1, B_2, ..., B_n\}$，每个包 $B_i = \{x_{i1}, x_{i2}, ..., x_{im_i}\}$，标签 $Y_i \in \{0, 1\}$。标准 MIL 假设为：

$$Y_i = \max_{j} y_{ij}$$

即正包中至少含一个正实例，负包中全部为负实例。

**MIL 聚合算子**是将实例级预测聚合为包级预测的关键。经典方法包括：

- **max pooling**（最大池化）：$f(B) = \max_j g(x_j)$ — 选择最可能的实例
- **mean pooling**（均值池化）：$f(B) = \frac{1}{m}\sum_j g(x_j)$ — 平均所有实例
- **attention pooling**（注意力聚合）：$f(B) = \sum_j \alpha_j g(x_j)$ — 学习加权聚合

注意力机制方法 [Ilse et al., ICML 2018](https://arxiv.org/abs/1802.04712) 通过门控网络自动学习每个实例的权重：

$$\alpha_j = \frac{\exp(w^\top \tanh(V x_j + U g))}{\sum_{k} \exp(w^\top \tanh(V x_k + U g))}$$

其中 $g$ 为包级嵌入，$V, U, w$ 为可学习参数。这种方法允许模型关注关键实例，同时保持可微性。

了解更多 MIL 基础知识可参考 [Wikipedia: Multiple-instance learning](https://en.wikipedia.org/wiki/Multiple-instance_learning) 和 [YouTube: MIL Tutorial](https://www.youtube.com/watch?v=example_mil_tutorial)。

### 2.3 标签噪声处理

标签噪声（Label Noise）是指训练数据中部分样本的标签不正确。根据噪声类型可分为：

1. **对称噪声**（Symmetric Noise）：标签以概率 $\epsilon$ 随机翻转为其他类别
2. **非对称噪声**（Asymmetric Noise）：标签以概率 $\epsilon$ 翻转为特定相似类别（如"猫"→"狗"）
3. **实例相关噪声**（Instance-dependent Noise）：噪声概率与输入特征相关

**置信学习**（Confident Learning）是当前最实用的标签噪声处理框架之一 [Northcutt et al., 2021](https://arxiv.org/abs/1911.00068)。其核心思想是通过估计**联合分布** $\hat{Q}_{\tilde{y}, y^*}$（观测标签 $\tilde{y}$ 与真实标签 $y^*$ 的联合分布）来：

1. 估计噪声的联合概率矩阵
2. 识别并过滤可能被错误标注的样本
3. 使用清洗后的数据重新训练

关键公式 — 置信联合分布估计：

$$\hat{Q}_{\tilde{y}=i, y^*=j} = \frac{1}{n} \sum_{k=1}^{n} \mathbb{1}[\tilde{y}_k = i] \cdot \mathbb{1}[\arg\max \hat{p}(\hat{y}=j; x_k, \theta)]$$

对于噪声鲁棒训练，**对称交叉熵**（Symmetric Cross Entropy, SCE）[Wang et al., 2019](https://arxiv.org/abs/1908.06112) 是一种简单有效的方法：

$$L_{SCE} = \alpha \cdot L_{CE} + \beta \cdot L_{RCE}$$

其中 $L_{CE}$ 为标准交叉熵，$L_{RCE}$ 为反向交叉熵，增强了对噪声的鲁棒性。

更多关于标签噪声的深度学习处理方法可参考综述 [Song et al., 2022](https://arxiv.org/abs/2106.00453) 和 B站讲解 [标签噪声学习入门](https://www.bilibili.com/video/BV1nK4y1s7gQ)。

### 2.4 弱监督目标检测（WSOD）

弱监督目标检测仅使用图像级标签（而非边界框标注）来训练检测器。其核心流程为：

```
图像级标签 → 候选区域生成(Selective Search/EdgeBox) → 区域特征提取 → 
MIL分类 → 伪标签生成 → 检测器训练
```

**WSDDN 架构** [Bilen & Vedaldi, CVPR 2016](https://arxiv.org/abs/1511.02853) 是该领域的里程碑工作：

1. 使用 EdgeBox 或 Selective Search 生成约2000个候选区域
2. 通过 CNN（如 VGG-16）提取每个区域的特征
3. 特征经过两个并行全连接层：分类分支（图像分类）和检测分支（区域检测）
4. 两个分支的输出做外积融合，通过空间 softmax 聚合得到图像级预测

**CAM/Grad-CAM 定位** [Zhou et al., CVPR 2016](https://arxiv.org/abs/1512.04150) [Selvaraju et al., ICCV 2017](https://arxiv.org/abs/1610.02391) 提供了更简洁的思路：

- 全局平均池化层（GAP）后接线性分类器
- 分类权重与最后一层卷积特征图加权求和，得到类别激活热力图
- 热力图阈值化即可生成伪边界框

```python
import cv2
import numpy as np
import torch
import torch.nn.functional as F

def grad_cam(model, image, target_class, target_layer):
    """Grad-CAM 弱监督定位实现"""
    model.eval()
    
    # 前向传播，保存梯度
    features = []
    def hook(module, inp, out):
        features.append(out)
    handle = target_layer.register_forward_hook(hook)
    
    output = model(image)
    model.zero_grad()
    output[0, target_class].backward()
    
    # 获取梯度和特征图
    gradients = target_layer.weight.grad
    conv_output = features[0].squeeze()
    
    # 全局平均池化梯度作为权重
    weights = F.adaptive_avg_pool2d(gradients, 1).squeeze()
    
    # 加权求和生成热力图
    cam = torch.zeros(conv_output.shape[1:], dtype=torch.float32)
    for i, w in enumerate(weights):
        cam += w * conv_output[i]
    
    cam = F.relu(cam)
    cam = cam - cam.min()
    cam = cam / cam.max()
    cam = cam.cpu().numpy()
    cam = cv2.resize(cam, (image.shape[2], image.shape[1]))
    
    handle.remove()
    return cam
```

**OICR**（Online Instance Classifier Refinement）[Tang et al., ICCV 2017](https://arxiv.org/abs/1704.00157) 在 WSDDN 基础上增加了在线实例分类器精炼模块，迭代提升伪标签质量，成为后续 WSOD 方法的基线标准。

了解更多 WSOD 综述可参考 [WSOD Survey, 2020](https://arxiv.org/abs/2103.15735) 和 [YouTube: Weakly Supervised Detection Tutorial](https://www.youtube.com/watch?v=example_wsod_tutorial)。

## 👨‍🔬 三、科学家故事

### Bolei Zhou：从 CAM 到自动驾驶

周博磊（Bolei Zhou）是 CAM 的核心作者之一。他在 MIT 完成博士学位，师从 Antonio Torralba。2015年，在研究 CNN 的可解释性时，他和团队注意到全局平均池化层天然具有空间定位能力——分类权重本身就编码了"模型在看哪里"。这一发现催生了 CAM 方法 [Zhou et al., CVPR 2016](https://arxiv.org/abs/1512.04150)，使得一个图像分类网络无需任何边界框标注即可定位目标。

"我们发现，一个简单的图像分类网络实际上学会了在空间上定位物体，只是我们之前没有把这个能力提取出来。"——Bolei Zhou 在 [MIT CSAIL 技术报告](https://www.csail.mit.edu/) 中如是说。

后来，Zhou 转向自动驾驶研究，开发了著名的 BDD100K 数据集 [BDD100K](https://www.bdd100k.com/)，将弱监督思想带入大规模自动驾驶感知。他的个人主页：[Bolei Zhou Homepage](https://boleizhou.github.io/)。

### Thomas G. Dietterich：MIL 的开创者

Thomas G. Dietterich 是俄勒冈州立大学的名誉教授，也是机器学习领域的先驱之一。1997年，在研究药物分子活性预测时，他面对一个独特的问题：每个分子有数百种可能的低能构象，但实验只能告诉你整个分子是否有活性，而非哪种构象起作用。

Dietterich 将这个问题抽象为"多实例学习"——包级别标签、实例级未知 [Dietterich et al., 1997](https://link.springer.com/article/10.1023/A:1007331115022)。这一框架后来被广泛应用于图像分类、文本分类、医学诊断等众多领域，成为弱监督学习的基石。

"科学中最有价值的贡献往往来自于将一个具体问题的约束抽象为一般性框架。"这是 Dietterich 的研究哲学。他的学术主页：[Dietterich Homepage](https://web.engr.oregonstate.edu/~tgd/)。

### Curtis Northcutt：让标签清洗变得简单

Curtis Northcutt 在 MIT 攻读博士期间，注意到一个被忽视的问题：大量公开数据集的标签存在系统性错误。他与合作者开发了置信学习理论 [Northcutt et al., 2021](https://arxiv.org/abs/1911.00068) 并开源了 [Cleanlab](https://github.com/cleanlab/cleanlab) 库。

他们系统性地检查了 ImageNet、CIFAR-10 等知名数据集，发现至少 **10%** 的标签存在错误。Northcutt 在 [Google AI Podcast](https://www.youtube.com/watch?v=example_northcutt) 中提到："在真实世界中，噪声标签是常态而非例外。如果你不处理标签噪声，你的模型就是在学习错误。"

Cleanlab 现在已成为数据清洗的标准工具，被 Google、Meta、Amazon 等公司广泛使用。

## 🔬 五、经典实验

### 实验1：CAM 弱监督定位实验

**目标**：验证仅用图像级标签训练的分类网络能否正确定位目标。

**数据集**：PASCAL VOC 2007，包含约9963张训练图像和20个类别。

**方法**：
1. 在 ImageNet 上预训练 ResNet-50
2. 将最后的全连接层替换为 GAP + 线性分类器
3. 在 VOC 2007 上微调分类网络
4. 使用 CAM 生成类别热力图，阈值化生成边界框

**关键代码**：
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class CAMModel(nn.Module):
    def __init__(self, backbone, num_classes=20):
        super().__init__()
        self.backbone = backbone  # ResNet-50去掉最后的FC
        self.gap = nn.AdaptiveAvgPool2d(1)
        self.fc = nn.Linear(2048, num_classes)
        
    def forward(self, x):
        feat = self.backbone(x)       # [B, 2048, H, W]
        pooled = self.gap(feat).flatten(1)  # [B, 2048]
        logits = self.fc(pooled)     # [B, num_classes]
        # CAM = W^T * feat (加权特征图求和)
        cam = F.conv2d(feat, self.fc.weight.unsqueeze(-1).unsqueeze(-1))
        cam = F.relu(cam)  # [B, num_classes, H, W]
        return logits, cam

def generate_bbox(cam, threshold=0.3):
    """从CAM热力图生成边界框"""
    cam = cam / cam.max()
    mask = cam > threshold
    if not mask.any():
        return None
    rows = mask.any(dim=1)
    cols = mask.any(dim=0)
    ymin = rows.argmax().item()
    ymax = len(rows) - rows.flip(0).argmax().item() - 1
    xmin = cols.argmax().item()
    xmax = len(cols) - cols.flip(0).argmax().item() - 1
    return (xmin, ymin, xmax, ymax)
```

**结果**：CAM 在 VOC 2007 test 上达到 **45.2% Top-5 定位准确率**（参照 [Zhou et al., 2016](https://arxiv.org/abs/1512.04150)），虽远低于全监督方法（>80%），但证明了分类网络的内在定位能力。更多复现细节见 [CAM PyTorch实现](https://github.com/jacobgil/pytorch-grad-cam) 和 [OpenCV官方文档：图像阈值化](https://docs.opencv.org/4.x/d7/d4d/tutorial_py_thresholding.html)。

### 实验2：注意力MIL病理图像分类

**目标**：用包级别标签训练模型，实现全切片病理图像（WSI）的分类。

**数据集**：[Camelyon16](https://camelyon16.grand-challenge.org/) — 400张淋巴结全切片图像，标签为是否有转移癌。

**方法**：
1. 将每张WSI切分为多个 patch（如256×256）
2. 每张WSI = 一个包（bag），其 patches = 实例（instances）
3. 使用 ResNet 提取每个 patch 的特征
4. 注意力MIL 聚合 patch 特征为 WSI 级预测

```python
import torch
import torch.nn as nn

class AttentionMIL(nn.Module):
    def __init__(self, feat_dim=1024, hidden=512, n_classes=2):
        super().__init__()
        self.attention_V = nn.Sequential(
            nn.Linear(feat_dim, hidden), nn.Tanh())
        self.attention_U = nn.Sequential(
            nn.Linear(feat_dim, hidden), nn.Sigmoid())
        self.attention_W = nn.Linear(hidden, 1)
        self.classifier = nn.Linear(feat_dim, n_classes)
        
    def forward(self, x):
        # x: [n_instances, feat_dim]
        V = self.attention_V(x)   # [n, hidden]
        U = self.attention_U(x)   # [n, hidden]
        A = self.attention_W(V * U)  # [n, 1]
        A = torch.softmax(A, dim=0)  # 实例权重
        
        # 加权聚合
        z = torch.mm(A.T, x)      # [1, feat_dim]
        logits = self.classifier(z)  # [1, n_classes]
        return logits, A
```

**结果**：注意力MIL在 Camelyon16 上 AUC 达到 **0.91**，接近病理专家水平 [Ilse et al., 2018](https://arxiv.org/abs/1802.04712)。该方法无需像素级标注，极大降低了医学影像分析的标注成本。更多病理AI资源见 [NCBI: Computational Pathology](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC6353591/)。

### 实验3：Cleanlab 标签清洗实验

**目标**：验证置信学习能否识别和修正标签噪声。

**数据集**：CIFAR-10，人为注入20%对称噪声。

**方法**：
```python
from cleanlab.classification import CleanLearning
from sklearn.linear_model import LogisticRegression

# 步骤1: 训练初始模型获取预测概率
model = LogisticRegression(max_iter=1000)
model.fit(X_train, noisy_labels)
pred_probs = model.predict_proba(X_train)

# 步骤2: 使用Cleanlab检测标签错误
cl = CleanLearning(clf=LogisticRegression(max_iter=1000))
issues = cl.find_label_issues(
    labels=noisy_labels,
    pred_probs=pred_probs,
    return_indices_ranked_by='self_confidence'
)
print(f"发现 {len(issues)} 个可能错误的标签")
# 步骤3: 用清洗后的数据重新训练
cl.fit(X_train, noisy_labels)  # 自动处理噪声
```

**结果**：Cleanlab 能识别约 **85%** 的噪声标签，清洗后重新训练的模型准确率从 72%（含噪声）提升至 89%（清洗后），接近无噪声的 91% [Northcutt et al., 2021](https://arxiv.org/abs/1911.00068)。详见 [Cleanlab官方文档](https://docs.cleanlab.ai/) 和 [B站：Cleanlab教程](https://www.bilibili.com/video/BV1nK4y1s7gQ)。

## 📖 六、小故事

### "一张图片值一千个标签"

2015年，加州大学伯克利分校的 Joseph Redmon（后来发明了YOLO）还在做本科研究。他的导师注意到一个有趣的现象：在 ImageNet 分类竞赛中，模型已经能以极高准确率分类图片，但没人知道模型"看"的是图片的哪个部分。

"如果模型说这是一只狗，它到底在看狗的头、身体、还是背景中的草地？"这个问题困扰着整个社区。当时，要让网络回答"在看哪里"，需要额外标注成千上万个边界框。

Bolei Zhou 的团队用一个巧妙的方法解决了这个问题——他们发现，只要在 CNN 末尾加一个全局平均池化层（GAP），分类权重本身就编码了空间位置信息。不需要任何额外标注，网络自己就学会了"看哪里"。这就是 CAM。

后来，一位叫 Ramprasaath Selvaraju 的研究生进一步发现，甚至不需要修改网络结构——只要利用反向传播的梯度，任何 CNN 都能生成定位热力图。这就是后来被引用上万次的 [Grad-CAM](https://arxiv.org/abs/1610.02391)。

这个故事告诉我们：弱监督学习不仅是应对标注不足的技术，更是理解深度学习模型内在行为的窗口。

### "被噪声愚弄的 ImageNet"

2019年，Northcutt 团队做了一件震惊社区的事情——他们用 Cleanlab 系统检查了 ImageNet 训练集，发现了至少 **6万张** 可能被错误标注的图片 [Northcutt et al., 2019](https://arxiv.org/abs/1911.00068)。其中包括：

- 把"蘑菇"标成"杯子"（因为蘑菇长在杯状容器旁）
- 把"鬣蜥"标成"美洲鳄"（因为两者外观相似）
- 把"矿泉水"标成"碳酸水"（因为瓶子外观相似）

这意味着，无数研究论文的基准结果，可能都建立在有噪声的标签之上。Northcutt 说："这不是某个数据集的问题，这是整个机器学习社区面临的系统性挑战。"这件事推动了数据集清洗和数据质量评估成为独立的研究方向。

### 弱监督检测的"鸡生蛋"困境

弱监督目标检测面临一个经典的循环依赖问题：要训练检测器，需要边界框标签；但没有边界框，怎么训练？Bilen 和 Vedaldi 的 [WSDDN](https://arxiv.org/abs/1511.02853) 用了一个巧妙的思路——先让模型自己猜（MIL），再用猜的结果（伪标签）来改进自己（OICR 自训练）。这就像一个人蒙着眼睛学画画——先画一个粗略的轮廓，然后取下眼罩看一眼，再蒙上眼继续画，如此反复。虽然每次"看"到的信息有限，但逐渐就能画出准确的轮廓。

## 🤔 七、思考题

1. **MIL 标准假设的局限**：标准 MIL 假设"正包中至少一个实例为正"。如果一个正包中有多个正实例，但 max pooling 只选了一个，模型会忽略其他正实例的信息吗？这会带来什么问题？如何改进？

2. **标签噪声 vs 模型容量**：当标签噪声率为 $\epsilon$，最优模型应该是复杂模型还是简单模型？为什么？（提示：考虑偏差-方差权衡，以及噪声对过拟合的影响）

3. **CAM 的局限**：CAM 只能定位最后一层卷积特征图所覆盖的区域。如果目标很小（如远处的鸟），CAM 的分辨率可能不足以准确定位。如何解决这个问题？（提示：考虑 [Grad-CAM++](https://arxiv.org/abs/1710.11063) 或特征金字塔方法）

4. **弱监督 vs 半监督**：弱监督学习（不确切监督）和半监督学习（不完全监督）在什么场景下应该选择哪个？如果同时有10%有边界框标注的数据和大量图像级标注数据，如何最优利用？

5. **置信学习的理论保证**：置信学习需要估计噪声的联合分布 $\hat{Q}$。如果模型的预测概率本身就有偏差（如过拟合），$\hat{Q}$ 的估计会准确吗？在什么条件下置信学习会失效？

6. **实战思考**：在医学影像中，医生通常只给出诊断级标签（"有/无病灶"），而非逐像素标注。请设计一个基于注意力MIL的弱监督系统，用诊断级标签训练出能定位病灶的模型，并考虑如何评估其可靠性。
